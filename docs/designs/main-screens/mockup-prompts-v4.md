## Main screens — `main-screens-sheet-v4.png`

> Edit the existing Joti 2×2 Android mockup sheet. Preserve its restrained blue-and-white theme, typography scale, spacing, floating pill navigation, compact buttons, thin dividers, and four-phone composition. Show Home as a populated dashboard with Add entry, one draft, recent entries, View all, and quiet total/company context. Keep History as the timeline with Add entry, search, filters, and date-grouped entries. Give Companies one Add company action, with no Add entry button. Keep Settings for account, appearance, Export CSV, Trash, and Sign out. Use concise, realistic work-journal examples and the exact four tab names Home, History, Companies, Settings. Avoid giant heroes, decorative badges, and nested cards.

## First use — `first-use-flow-sheet-v1.png`

> Create a matching 2×2 Android sheet for the first-use journey: (1) Joti sign-in with Continue with Google; (2) empty Home with Add company as the next action; (3) Add company form with name, optional job title, start/end dates, and Save company; (4) New entry, task-details step 1 of 3, with date, selected company, Project / category set to General / Adhoc, task title, What I did, Saved as draft, and Next. Do not show tabs inside forms. A separate project is optional; the category selection is required. Keep copy and layout simple.

The first generated first-use image used the label “Project (optional).” A targeted edit corrected it to “Project / category” before the final file was saved.
