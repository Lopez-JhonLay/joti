# Joti 2D Mascot

`joti-actions-sheet-v1.png` is the original combined 3×3 action concept sheet in the selected 2D cartoon style. It is preserved alongside nine separate transparent PNGs. These are still poses, not animated files.

## Individual figures

Each PNG is 450×450 pixels: the original 418×418 grid cell plus 16 pixels of transparent padding on every side. The artwork is extracted without resizing, redrawing, or changing its pixels. Equal canvas sizes preserve the sheet's relative figure scale.

Read the figures from left to right, top to bottom:

| Row | Column | Action    | Intended app use                                 |
| --- | ------ | --------- | ------------------------------------------------ |
| 1   | 1      | Welcome   | Onboarding and greeting                          |
| 1   | 2      | Reflect   | Journaling prompts and recalling accomplishments |
| 1   | 3      | Write     | Entry creation and editing                       |
| 2   | 1      | Saved     | Confirmed successful save                        |
| 2   | 2      | Celebrate | Completed entries and accomplishments            |
| 2   | 3      | Search    | Work-history search                              |
| 3   | 1      | Organize  | Companies and projects                           |
| 3   | 2      | Rest      | Quiet empty states and unfinished drafts         |
| 3   | 3      | Retry     | Save-failure recovery and encouragement          |

Use the mascot selectively, with accessible accompanying copy. A success pose must reflect a confirmed successful operation. Future animation must follow the app-wide reduced-motion and performance guidance in `docs/DESIGN_SYSTEM.md`.

All figures were checked for grid-cell clearance, transparent padding, and lossless pixel preservation. The Organize pose is now used in the company empty state, following `docs/designs/supporting-screens/empty-and-project-sheet-v1.png`; its size and contrast still require physical-phone review. Other poses remain unintegrated.
